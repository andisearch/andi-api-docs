## Base URL

```text
https://api.andiai.com
```

## Authentication

All requests require an API key passed in the `x-api-key` header. Get your key from the [API Console](https://console.andiai.com).

```bash
curl "https://api.andiai.com/api/v1/search?q=hello+world" \
  -H "x-api-key: YOUR_API_KEY"
```

Prefer a command line? The [Andi CLI](/getting-started/cli) wraps search, fetch, and a local MCP server:

```bash
npx -y @andiai/cli search "hello world"
```
