The Andi AI Search API has two endpoints: search and fetch.

## Base URL

```text
https://api.andiai.com
```

`https://search-api.andisearch.com` remains supported as a legacy alias of `api.andiai.com`.

## Authentication

Pass your API key in the `x-api-key` header with every request:

```bash
curl "https://api.andiai.com/api/v1/search?q=test" \
  -H "x-api-key: YOUR_API_KEY"
```

Get an API key from the [API Console](https://console.andiai.com).

## Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/v1/search` | Search the web |
| `POST` | `/api/v1/search` | Search the web with parameters in a JSON body. Preferred for location-bearing requests. |
| `GET` | `/api/v1/fetch` | Fetch a web page as clean extracted content (JSON or LLM-ready markdown). See [content retrieval](/search/content-retrieval). |

The search endpoint supports five [search modes](/search/search-modes) (`auto`, `fast`, `low-cost`, `deep`, `exhaustive`), multiple output formats, and filtering by domain, date, content type, and more.

Browse the **Endpoints** section in the sidebar to try the endpoints in the interactive playground.

## Pricing

Every JSON response includes `metrics.cost_dollars` — the amount charged to your account for that request in USD, after any discounts.

**Search:** Calls using `searchMode` (or no mode parameter) are priced on outcome — the charge reflects the actual work performed, so simpler queries cost less. Legacy calls with an explicit `depth=fast` or `depth=deep` parameter are charged a fixed per-call rate: $0.007 for fast, $0.025 for deep.

**Fetch:** Flat $0.001 base per request, plus $0.05 per 1M tokens of extracted content. Failed fetches (422 and 503 responses) are free.
